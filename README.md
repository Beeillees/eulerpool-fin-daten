# Depot-Daten

Home-Assistant-App, die Kennzahlen, Kursziele, Leerverkäufe und Termine zu Depot- und Beobachtungstiteln
von Eulerpool holt und als Sensoren bereitstellt.

## Installation
1. **Einstellungen → Apps → App-Store**, oben rechts **⋮ → Repositories**
2. `https://github.com/Beeillees/eulerpool-fin-daten` hinzufügen
3. **Depot-Daten** installieren und starten

Schlüssel: `eulerpool_token:` in der `secrets.yaml` oder im Feld **token** der App.
